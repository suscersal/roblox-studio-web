Это упрощённая демо-сцена на three.js с тем же интерфейсом, что и у настоящего редактора. Он открывает реальные .rbxl-файлы — запусти его локально или установи APK.






  
Что умеет

  
Самописный бинарный парсер .rbxl (LZ4, interleaved-массивы, delta-referent’ы) и веб-интерфейс на Flask.

  

    
📂 .rbxl
Открытие и сохранение: байтовая копия или полная пересборка файла.

    
🌳 Explorer
Дерево объектов с иконками классов и поиском.

    
🧊 3D
Вьюпорт: Part, WedgePart, SpherePart, TrussPart, Seat и другие.

    
📝 Properties
Инспектор свойств и редактор CFrame.

    
💻 Lua
Редактор скриптов с подсветкой Lua (CodeMirror).

    
➕➖ Add / Delete
Добавление и удаление объектов — 33 класса на выбор.

    
▶ Play
Простая физическая симуляция и камера от первого лица (экспериментально).

    
☁ Publish
Публикация в Roblox через Open Cloud API.

    
📱 Android
APK: WebView + встроенный Python (Chaquopy) и hot-обновления без переустановки.

Установка

  
Редактору нужен Python-сервер (Flask), поэтому на GitHub Pages сам редактор не запустится — страница только показывает демо. Выбери способ:

  

    
🖥 PC / Termux

      
git clone https://github.com/suscersal/roblox-studio-web.git
cd roblox-studio-web
python3 app.py

      
Flask поставится сам при первом запуске. Открой http://localhost:47182

    
📱 Android APK

      
Скачай последний APK в Releases и установи (разреши установку из неизвестных источников). Обновления прилетают сами.


      Releases

    
📦 Без git

      
Скачай архив и распакуй — git не нужен:

      
curl -L -o rsw.zip https://github.com/suscersal/roblox-studio-web/archive/refs/heads/main.zip
unzip rsw.zip && cd roblox-studio-web-main
python3 app.py
